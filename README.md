# 地铁跑酷 · 浏览器重建试玩

从用户手机上的 `com.kiloo.subwaysurf` 7.07.0 APK 恢复角色、蒙皮、动画和环境资源，并用 Three.js 实现浏览器跑酷交互。经典路线已接入完整的 49 个命名路段及原版章节配置；完整 Android 客户端及其他模式尚未移植。

## 本机启动

```sh
npm ci
npm run dev
```

打开终端打印的本机地址。`npm test` 验证移动、碰撞、金币、暂停、车顶等行为；`npm run build` 生成 `dist/`。

## 操作与角色

- 方向键 / WASD：左右换道、向上跳跃、向下翻滚；空格也可跳跃。
- P / Esc：暂停或继续；触屏可上下左右滑动。
- E / 双击画面：启动普通滑板；本地试玩每局提供 3 块，撞击消耗保护。
- 失败后可在 8 秒内选择「试玩复活」；本地每局一次，保留已跑距离、金币与积分。
- 「导入角色」读取本机 GLB，在浏览器内替换外观；文件不上传至游戏服务器。
- GLB 自带的动画会按名称匹配 run / jump / roll。没有骨骼或动画的模型只能显示静态外观，需要完成绑骨和动作适配后才能获得对应动作。
- 默认玩家角色为 Hi3D 黄色小怪兽，刷新后恢复该角色，无需手动导入。
- 当前追逐者为新的 Hi3D 红鼻子长耳角色，单个角色替代原来的警卫与狗组合。追逐、绊倒、抓捕和复活判定继续使用已有经典模式规则。
- 黄色角色使用完整全身模型；26 根骨骼层级和跑步 / 跳跃 / 翻滚曲线来自已恢复的 Jake 资源，按黄色角色体型重新确定关节位置、蒙皮权重及休息姿态对齐。短腿接地经过适配，不等于原版角色的逐顶点动作。
- 翻滚全程保持角色尺寸，不再缩放骨骼。连续输入延长翻滚状态时，动画持续循环；循环首尾姿态已对齐，停止输入后恢复跑步。碰撞仍采用游戏原有的翻滚判定。
- 游戏版模型小于 7 MB、约 8 万三角形，包含 20 条原版动作来源，保留原贴图。Hi3D 模型手臂与躯干存在粘连，因此摆臂幅度已减小，腋下与手部仍有局部形变，尚不是手工精修的动画拓扑。

角色来源、骨骼映射及动作出处见 `public/assets/character/yellow-runner.json`；本机上级 `tools/character-pipeline/build-yellow.mjs` 可以从原全身 GLB 和已提取资源重新生成。`scripts/character-preview.html` 是仅用于本地检查的动作预览页，不进入正式构建。

红鼻子追逐者来自 Hi3D 任务 `37e98af3991e4cacb6817b0fd75413cb`，游戏版本约 3.65 MB、74,992 个三角形，保留双脚、双耳、红鼻子和完整尾巴；原始 45.9 MB 文件未覆盖。模型重新绑定 18 根警卫来源骨骼，并适配 7 条原版警卫动作，尾巴跟随骨盆、耳朵跟随头部。短臂与背部动作幅度、体型和接地经过显示适配，融合部位仍可能有局部形变。追逐场景只实例化这个角色，原警卫与狗不再加载蒙皮/动画。来源与转换记录见 `public/assets/character/red-nose-chaser.json`，本机生成脚本为上级 `tools/character-pipeline/build-red-chaser.mjs`；`scripts/chaser-preview.html` 用于本地动作检查。

## 资源与实现

`public/assets/recovered/manifest.json` 保留提取资源的来源引用与限制说明。Jake 使用真实网格、26 根蒙皮骨骼、绑定矩阵和跑步 / 翻滚 / 跳跃曲线；动画按 Unity 曲线切线采样。列车、障碍、金币、双铁轨及城市建筑来自 APK 中可追溯的资源。

`src/config.js` 分别记录原生代码已证实的默认值与浏览器调校值。网页版采用每 10 个 Unity 世界单位对应 1 个显示单位的比例；原生构造器默认值可能被序列化数据或 XLua 热更新覆盖，不能视为手机运行时实测值。相机、着色器、声音及角色碰撞响应仍有浏览器实现和调校。

`src/route-generator.js` 执行原始层级、章节和随机选择；`src/environment-layout.js` 处理环境类型、强制区间及模型拼接；`src/game-core.js` 为独立于渲染帧率的模拟；`src/asset-adapter.js` 负责 Unity 提取资源和 GLB 适配；`src/main.js` 负责场景与交互。资源更新后可从此目录执行：

```sh
node scripts/sync-assets.mjs
```

该脚本合并本项目上级的基础资源以及 powerups、flight、classic 资源补丁，并重算公开资源校验和。单独取得网页仓库时，已有的 `public/` 资源足以运行，不必重新提取 APK。

## 逆向证据范围

本机上级目录保存 APK、可复现提取脚本、元数据恢复报告、REA 校验输出、局部原生反汇编及验证记录。原 APK SHA-256 为 `9ecc5d383ae4d160695e1956d6e252a0cad75fbe23e2888b01566f611d0b4b5d`。

REA CLI 已独立解析恢复后的类型 / 方法 / 字段表。恢复文件最初 8 字节是为解析器构造的 IL2CPP v31 兼容头；正文依据包内加载逻辑恢复。原生方法指针表已找到，但部分代码页仍有保护或置换，因此不能把表项映射称为完整源码恢复。完整 REA 原生代码关联未通过；已确认的公式另有局部反汇编与字段证据。

## 本轮关卡移植

- 默认路线的 49 个命名路段、34 个章节配置、5 个章节组、60 个递归占位定义全部来自 APK。另有教程段资源；教程引导事件未启用。
- 章节按权重展开条目，并执行原生半随机列表的待选/已用回补及回退规则；章节门控保留最早距离、最晚距离、出现次序、重复间隔及禁止前驱。开始/中间/结束三阶段按原数量约束运行。
- Selector、Randomizer、RandomizeOffset、Mirror 与预制体初始化按已恢复的生命周期执行，保留禁用分支和原始局部变换。每段保存选择记录与资源来源。
- 金币按原始 Hermite 曲线、间距、速度缩放和跳过索引生成；普通速度增长不触发每帧重排，高速切换的重排属于独立事件。移动列车保留原版静态压缩碰撞代理，车身与车上金币按角色距离移动。
- 列车各车厢单独显示，碰撞体与模型分离；斜坡使用原始旋转盒和胶囊表面，可从坡面走上车顶。
- 当前 MexicoCity 主题的 20 类终端模型及 8 种环境映射均已提取。环境按原始强制区间、重复距离和 90 单位块长拼接；单轨居中、双轨在两侧，车站及大型场景采用不同的起止段长度。

测试覆盖全部 49 个路段的 16 个种子、完整资源引用、半随机抽取与章节约束、真实斜坡及移动列车碰撞，并验证长序列环境生成。所有验证针对已恢复的原生回退逻辑；不会证明 XLua 热更新与手机运行时完全一致。

已接入 36 个源 SpawnPoint 的经典原生选择路径：首个距离门槛 2000、全局间隔 2400 Unity 单位（显示单位 200/240），保留原候选顺序、权重、各类型间隔和整数抽选端点。已实现磁铁、弹跳鞋、双倍积分、普通喷气背包及原始拾取模型；未实现的钥匙和宝箱仍占原抽选位置，选中时留下诊断并不生成替代物，不重新抽选。迁移检测方法 81341 明确返回 false，支持该 APK 的旧版原生路径；线上热更新仍需另查。

三类道具使用原生七级持续时间表；本地档案为等级 1、道具等级 0（10 秒），重复拾取刷新而不累加。磁铁按源球形范围和平方时间曲线吸币；跑鞋采用源上升曲线、4 单位跳高及倾斜吸附胶囊；积分按每个新增整米的当时倍率累计，金币按原始倍率乘 2 换分。双倍拾取先结算奖励、再打开倍率。暂停冻结计时，重开清除效果。吸附终点适配黄色角色身体，不是手机角色附着点的逐帧复现。原生方法、字节哈希和判读位于上级 `analysis/powerups/`。`scripts/powerup-preview.html` 是不进入正式构建的定向回归场景。

普通喷气背包按原始起飞曲线、9.5 显示单位高度、两倍速度和距离终点运行，生成空中金币与真实落地区段。滑板保护持续 30 秒，飞行期间隐藏并暂停计时，撞击后经过源粒子延迟、清除附近障碍并弹起。原生滑板冷却复位仍未完全闭环，网页版明确使用行进距离解除冷却；高速飞行落地也保留有标注的额外安全区适配。证据和限制见上级 `analysis/verification/flight-status.json`。

## 经典碰撞、追逐与复活

- 外侧越界与列车侧碰触发绊倒；侧碰按当前换道距离回弹。首次绊倒的易被抓窗口为 5 秒，期间再次绊倒启动约 0.2 秒的死亡请求；滑板可吸收致命结果，飞行在提交死亡时再次检查。
- 警卫追近采用源 0.7 秒平滑曲线，从 30 接近至 10 Unity 单位，恢复后在 1.5 秒内退回。1 秒内再接触不同实体的源连续碰撞分支也已接入。
- 219 个碰撞体带有 APK 中的真实标签和层。只有实际 Hit 层触发器走非实体碰撞分支；不能仅凭 Stumble 标签忽略实体碰撞。
- 黄色角色增加 11 条经典受击/被抓动作。原版 MexicoCity 警卫和狗的真实蒙皮、绑定矩阵、贴图和动作保留在来源资源中；导出时独立纠正压缩权重解码，并验证休息姿态误差。其网格绑定在动画根坐标，不能重复应用原 Renderer 所在骨节点变换。当前实际显示已替换为上述红鼻子追逐者。
- 复活保持同局距离、金币、积分、路线、横向位置。按源约 0.144 秒延迟、250 Unity 单位乘速度归一化的范围清障，以及 15 Unity 单位跳高恢复跑动。复活弹窗期间道具与速度增长计时继续；暂停冻结这些计时。一次免费复活与三块滑板是本地试玩配置，不是恢复的玩家账户库存。

证据分别位于上级 `analysis/classic/collision/collision-findings.json`、`analysis/classic/revive/findings.json`、`analysis/classic/resources/`。`scripts/classic-preview.html` 是不会进入正式构建的定向回归页。

碰撞方向目前使用浏览器连续运动接触面分类；原生 ObstacleImpactUtil 的两个保护区常量尚未恢复，HitBounceOnly 的细分角落响应仍不完整。受击动画选取、追逐者可见性/淡出、跟随横移、失败后的抓取衔接和体型比例属于显示适配，尚未还原完整警卫 AI 与抓捕演出。掉入缺口后的复活会恢复到清空后的地面，这是明确的浏览器修复。原生死亡瞬间的一次最低速度写入尚未模拟；不会把它错误延长为整个死亡延迟期间的持续减速。

当前优先普通经典单局。仍待补齐的相关内容包括上述碰撞与追逐细节、宝箱/钥匙奖励、教程引导、原版音效/粒子/相机及 XLua/设备运行时对照。其他竞赛、活动、账号和经济系统不在当前范围。浏览器采用可重放的本地随机数序列，环境外观使用独立随机源；不会与手机的同名种子逐帧相同，也不是完整 Unity 渲染/物理移植。
