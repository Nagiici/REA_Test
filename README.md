# 地铁跑酷 · 浏览器重建试玩

从用户手机上的 `com.kiloo.subwaysurf` 7.07.0 APK 恢复角色、蒙皮、动画和环境资源，并用 Three.js 实现浏览器跑酷交互。经典路线已接入完整的 49 个命名路段及原版章节配置；完整 Android 客户端及其他模式尚未移植。

## 本机启动

```sh
npm ci
npm run dev
```

打开终端打印的本机地址。`npm test` 验证移动、碰撞、金币、暂停、车顶等行为；`npm run build` 生成 `dist/`。

## 操作与角色

- 方向键 / WASD：左右换道、向上跳跃、向下翻滚；空格也可跳跃。
- P / Esc：暂停或继续；触屏可上下左右滑动。
- 「导入角色」读取本机 GLB，在浏览器内替换外观；文件不上传至游戏服务器。
- GLB 自带的动画会按名称匹配 run / jump / roll。没有骨骼或动画的模型只能显示静态外观，需要完成绑骨和动作适配后才能获得对应动作。
- 刷新页面恢复原角色 Jake。黄色角色的 Hi3D 生成与后续绑骨仍待完成。

## 资源与实现

`public/assets/recovered/manifest.json` 保留提取资源的来源引用与限制说明。Jake 使用真实网格、26 根蒙皮骨骼、绑定矩阵和跑步 / 翻滚 / 跳跃曲线；动画按 Unity 曲线切线采样。列车、障碍、金币、双铁轨及城市建筑来自 APK 中可追溯的资源。

`src/config.js` 分别记录原生代码已证实的默认值与浏览器调校值。网页版采用每 10 个 Unity 世界单位对应 1 个显示单位的比例；原生构造器默认值可能被序列化数据或 XLua 热更新覆盖，不能视为手机运行时实测值。相机、着色器、声音及角色碰撞响应仍有浏览器实现和调校。

`src/route-generator.js` 执行原始层级、章节和随机选择；`src/environment-layout.js` 处理环境类型、强制区间及模型拼接；`src/game-core.js` 为独立于渲染帧率的模拟；`src/asset-adapter.js` 负责 Unity 提取资源和 GLB 适配；`src/main.js` 负责场景与交互。资源更新后可从此目录执行：

```sh
node scripts/sync-assets.mjs
```

该脚本读取本项目上级的 `analysis/unity-resources/runtime-assets/`。单独取得网页仓库时，已有的 `public/` 资源足以运行，不必重新提取 APK。

## 逆向证据范围

本机上级目录保存 APK、可复现提取脚本、元数据恢复报告、REA 校验输出、局部原生反汇编及验证记录。原 APK SHA-256 为 `9ecc5d383ae4d160695e1956d6e252a0cad75fbe23e2888b01566f611d0b4b5d`。

REA CLI 已独立解析恢复后的类型 / 方法 / 字段表。恢复文件最初 8 字节是为解析器构造的 IL2CPP v31 兼容头；正文依据包内加载逻辑恢复。原生方法指针表已找到，但部分代码页仍有保护或置换，因此不能把表项映射称为完整源码恢复。完整 REA 原生代码关联未通过；已确认的公式另有局部反汇编与字段证据。

## 本轮关卡移植

- 默认路线的 49 个命名路段、34 个章节配置、5 个章节组、60 个递归占位定义全部来自 APK。另有教程段资源；教程引导事件未启用。
- 章节按权重展开条目，并执行原生半随机列表的待选/已用回补及回退规则；章节门控保留最早距离、最晚距离、出现次序、重复间隔及禁止前驱。开始/中间/结束三阶段按原数量约束运行。
- Selector、Randomizer、RandomizeOffset、Mirror 与预制体初始化按已恢复的生命周期执行，保留禁用分支和原始局部变换。每段保存选择记录与资源来源。
- 金币按原始 Hermite 曲线、间距、速度缩放和跳过索引生成；普通速度增长不触发每帧重排，高速切换的重排属于独立事件。移动列车保留原版静态压缩碰撞代理，车身与车上金币按角色距离移动。
- 列车各车厢单独显示，碰撞体与模型分离；斜坡使用原始旋转盒和胶囊表面，可从坡面走上车顶。
- 当前 MexicoCity 主题的 20 类终端模型及 8 种环境映射均已提取。环境按原始强制区间、重复距离和 90 单位块长拼接；单轨居中、双轨在两侧，车站及大型场景采用不同的起止段长度。

测试覆盖全部 49 个路段的 16 个种子、完整资源引用、半随机抽取与章节约束、真实斜坡及移动列车碰撞，并验证长序列环境生成。所有验证针对已恢复的原生回退逻辑；不会证明 XLua 热更新与手机运行时完全一致。

尚未重建：SpawnPointManager 的道具选择和完整道具效果、教程事件、其他路线/竞赛模式及账号、活动、任务、经济系统。浏览器采用可重放的本地随机数序列，环境外观使用独立随机源；不会与手机的同名种子逐帧相同。地面阴影、环境跨路段衔接、摄像机和角色碰撞反应也不是完整 Unity 渲染/物理移植。
